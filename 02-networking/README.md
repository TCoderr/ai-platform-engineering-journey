# Networking

Networking fundamentals required for cloud infrastructure, containers, Kubernetes, and distributed systems.

## Objectives

- Understand how computers communicate over networks
- Understand TCP/IP and network addressing
- Learn subnetting and CIDR
- Understand DNS and routing
- Understand HTTP/HTTPS and TLS
- Understand firewalls, NAT, proxies, and load balancers
- Build the networking foundation required for AWS VPC and Kubernetes
